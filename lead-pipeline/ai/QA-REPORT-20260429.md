## UI Bugs Found

All bugs also logged in `ai/UI-ISSUES.md` (Open section).

### BUG-1 (Medium): Letter date in ISO format
Letter preview shows "Berlin, 2026-04-29" instead of German format "29. April 2026". Every exported Serienbrief will have wrong date format. Screenshot: `qa-screenshots/phase2-allgreen.png`

### BUG-2 (Low): Panel contrast insufficient
Preview panel `#E5E3DD` vs editor panel `#F1EFEA` — RGB distance only ~21 units. Panels look nearly identical, making it hard to distinguish the read-only preview from the editable editor. Roman flagged this in Round 2 and Round 3 of feedback. Needs either darker preview bg (e.g. `#D5D3CD`) or true white editor bg.

### BUG-3 (Low): Queue name truncation without tooltip
Long company names (e.g. "Compri Handelsgesellschaft fur Verbandsmaterialien...") are truncated in the 300px queue panel. No `title` attribute on `.qitem-name` elements for hover reveal.

## Missing Feature

**No grammar/quality check on export-ready letters.** AI-generated German text (Komplimente, Mehrwerte, Leistung) goes directly to PDF export without any validation. Flo would need to manually read 85+ letters for grammar, tone, and factual accuracy. Options:
- Pre-export LLM grammar pass (batch all letter text, return corrections)
- Inline quality indicators (flag short/suspicious text in the editor)
- Export-time validation gate (block export if text quality score is below threshold)
